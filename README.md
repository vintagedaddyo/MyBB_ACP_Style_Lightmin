# MyBB_ACP_Style_Lightmin

MyBB: Lightmin - Admin CP

Style Authors: Mycreedo & Vintagedaddyo

 * MyCreedo Site: https://mybboard.pl/user-35621.html
 * Vintagedaddyo Site: http://community.mybb.com/user-6029.html

Lightmin is a free light colored ACP style for MyBB 1.8.x. Style is responsive and multi-color. All panel sections (even custom!) has own pastel color! Does not require installation of extra plugins though simple mode must die plugin is provided.

### INSTALL: ###

Follow this steps to install it correctly.

1. Open the "upload" folder and upload all the content to the root of your forum.

2. Go to ACP > Configuration > Settings > Control Panel Preferences (Global) > Select "Lightmin" in "Control Panel Style" and press "Save Settings".

* 2 (alt). Go to ACP > Home > Preferences > Select "Lightmin" in "Admin Control Panel Theme" and press "Save Personal Notes & Preferences".
